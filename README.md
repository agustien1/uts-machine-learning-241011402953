## Deskripsi

Repository ini dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS) mata kuliah Machine Learning. Tugas ini membahas penerapan algoritma **Linear Regression** dan **Logistic Regression** menggunakan Python, serta membandingkan hasil implementasi manual dengan library Scikit-learn.

## Tujuan

1. Memahami konsep Linear Regression untuk memprediksi nilai numerik.
2. Memahami konsep Logistic Regression untuk klasifikasi data.
3. Mengimplementasikan algoritma Machine Learning secara manual menggunakan NumPy.
4. Mengevaluasi model menggunakan metrik yang sesuai.
5. Membandingkan hasil implementasi manual dengan Scikit-learn.
